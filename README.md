# 💻 LABORATORY ACTIVITY
## Activity Title: "From Algorithm to C++"

---

### 🎯 Objective
The objective of this activity is to convert a simple real-world problem statement and algorithm into a working C++ program.

---

### 📝 Problem Statement
Create a C++ program that prompts the user to enter the following information:
1. **Student Name**
2. **Quiz 1 Grade**
3. **Quiz 2 Grade**
4. **Quiz 3 Grade**

After receiving the inputs, the program should calculate the student's overall quiz average and display the final result.

---

### 💻 Expected Input / Output Example

```text
Enter Student Name: Juan
Enter Quiz 1: 80
Enter Quiz 2: 90
Enter Quiz 3: 85

Student: Juan
Average: 85
